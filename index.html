On April 2, Cursor launched version 3, codenamed Glass. The release replaced Cursor's Composer pane with a dedicated Agents Window — a standalone interface built from scratch around managing multiple AI agents.

Three days earlier, OpenAI published codex-plugin-cc on GitHub. The plugin installs directly inside Claude Code, Anthropic's terminal-based coding agent. It provides six slash commands.

The structural insight is not that these tools launched in the same week — it is that they launched in a way that makes them composable.

The Toolkit

Four tools.
One canvas.

Adnota ships with four purpose-built tools, each solving a distinct problem with the web as you read it. Every annotation is anchored intelligently — surviving page refreshes, SPA navigations, and layout shifts.

🗑

Eraser

Permanently hide any page element. Hover to preview, click to erase. Scroll the mouse wheel to walk up the DOM and find the exact container you want gone. Ad-detection promotes erasures domain-wide automatically.

How it works

Install once.
Own the web forever.

1

Install from Chrome Web Store

One click, no account, no sign-in. The extension injects itself into every page you visit, invisibly, until you need it.

2

Annotate any page

Open the radial menu or use keyboard shortcuts. Erase distractions, highlight what matters, drop notes, resize layouts.

3

Come back to your canvas

Every annotation auto-restores on the next visit. Your edited web stays edited — silently, privately, persistently.

🔐

No accounts

Nothing to sign up for. Nothing to log into. The extension works immediately.

☁️

No cloud

All data lives in chrome.storage.local. Never leaves your browser.

👁

No tracking

No analytics, no telemetry, no usage data collected. What you annotate is yours alone.

🔍

Auditable

No network requests, no hidden calls. Open DevTools and verify it yourself — the code does exactly what it says.
